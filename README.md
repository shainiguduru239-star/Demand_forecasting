# Demand Forecasting Using Regression Models

## 📌 Project Overview

Demand Forecasting Using Regression Models is a machine learning project that predicts customer demand using sales and customer-related data.

The project uses regression techniques to analyze factors such as age, category, item purchased, season, payment method, previous purchases, ratings, and discounts to predict the purchase amount.

## 🎯 Objective

The main objective of this project is to build a machine learning model that can predict demand accurately and help understand customer purchasing patterns.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Linear Regression

## 📂 Dataset

The project uses a store sales dataset containing information such as:

- Customer ID
- Age
- Gender
- Category
- Item Purchased
- Amount
- Season
- Payment Method
- Item Rating
- Discount Applied
- Previous Purchases

## ⚙️ Project Workflow

1. Load the dataset.
2. Explore the available data.
3. Convert categorical data into numerical values.
4. Perform feature engineering.
5. Select features and target variable.
6. Scale the features using StandardScaler.
7. Split the data into training and testing sets.
8. Train the regression model.
9. Make predictions.
10. Evaluate the model using regression metrics.
11. Visualize the results.

## 🤖 Machine Learning Model

The project uses **Linear Regression** to predict the target value.

### Evaluation Metrics

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
